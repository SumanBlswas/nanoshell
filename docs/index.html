Module

NanoShell.fs

Native C-level File System reading, writing, directory listing, creation, and deletion with zero Node.js overhead.

NanoShell.fs.readFile(filePath: string): string

Reads file contents from disk synchronously into a JavaScript string.

NanoShell.fs.writeFile(filePath: string, content: string): boolean

Writes content to disk file. Returns true on success.

NanoShell.fs.exists(filePath: string): boolean

Checks if a file or folder path exists on disk.

NanoShell.fs.readDir(dirPath: string): string (JSON)

Lists directory contents returning JSON array: [{"name":"app","isDir":true}].

NanoShell.fs.mkdir(dirPath: string): boolean

Creates nested directory folders on disk.

NanoShell.fs.remove(filePath: string): boolean

Deletes file or directory path from disk.

JavaScript Example 
// Read a text file from disk
const content = NanoShell.fs.readFile("C:\\path\\to\\notes.txt");
console.log("File Content:", content);

// Write to a new file
const success = NanoShell.fs.writeFile("C:\\path\\to\\output.txt", "Saved with NanoShell!");

// Check existence & list folder
if (NanoShell.fs.exists("C:\\Projects")) {
    const files = JSON.parse(NanoShell.fs.readDir("C:\\Projects"));
    console.log("Directory Entries:", files);
}
Module

NanoShell.os

Query OS kernel telemetry, architecture, total/available memory, and CPU hardware specs.

NanoShell.os.getInfo(): string (JSON)

Returns system telemetry JSON: {"platform":"Windows","arch":"x64","cores":8,"ramTotalMB":16384,"ramFreeMB":8192}.

JavaScript Example 
const sysInfo = JSON.parse(NanoShell.os.getInfo());
console.log(`OS: ${sysInfo.platform} ${sysInfo.arch}`);
console.log(`CPU Cores: ${sysInfo.cores}, Free RAM: ${sysInfo.ramFreeMB} MB`);
Module

NanoShell.shell

Execute native Windows PowerShell/CMD commands and open URLs/files in default OS applications.

NanoShell.shell.openExternal(urlOrPath: string): boolean

Opens a web URL, file, or directory folder in default Windows OS app via Win32 ShellExecuteA.

NanoShell.shell.exec(command: string): string (JSON)

Executes CLI command in CMD/PowerShell returning {"stdout":"...","stderr":"","exitCode":0}.

JavaScript Example 
// Open URL in default browser
NanoShell.shell.openExternal("https://github.com");

// Execute CLI command
const res = JSON.parse(NanoShell.shell.exec("dir"));
console.log("Command Output:", res.stdout);
Module

NanoShell.process

Query OS Task Manager process list, spawn detached background sub-processes, and terminate processes.

NanoShell.process.list(): string (JSON)

Returns JSON array of running processes: [{"pid":1000,"name":"nanoshell.exe"}].

NanoShell.process.spawn(command: string): string | null

Spawns a detached process via Win32 CreateProcessA returning {"pid": 1234}.

NanoShell.process.kill(pid: number): boolean

Terminates process by PID via Win32 TerminateProcess.

NanoShell.window.minimize() | maximize() | restore() | close() | center()

NanoShell.window.setTitle(title: string): void

Module

NanoShell.shm (Exclusive Engine)

Zero-copy C-RAM shared memory matrix allowing sub-0.01ms data exchange between C++ plugins, GPUs, and JS.

NanoShell.shm.createRegion(name: string, sizeBytes?: number): boolean

Allocates a Win32 CreateFileMappingA shared C-memory page buffer in RAM.

NanoShell.shm.read(name: string): string | null

Reads ultra-fast zero-copy string data directly from C memory via MapViewOfFile.

NanoShell.shm.write(name: string, data: string): boolean

Writes zero-copy string data to shared C memory in under 0.01ms without IPC stringification.

Module

NanoShell.snapshot (Exclusive Engine)

Instant application cold-start snapshot engine (< 1ms thaw time from disk binary heap).

NanoShell.snapshot.freezeState(path?: string): boolean

Serializes active state directly to a binary .snap disk file with header verification.

NanoShell.snapshot.thawState(path?: string): string | null

Restores application state instantly from binary disk snapshot on cold start in under 1ms.

Module

NanoShell.gpu (Exclusive Engine)

GPU hardware telemetry, VRAM monitoring, and dynamic frame rate capping (60 FPS, 120 FPS, 144 FPS).

NanoShell.gpu.getInfo(): string (JSON)

Returns hardware GPU adapter details via DXGI: {"name":"NVIDIA...","vramMB":8192,"vendor":"Win32/DXGI"}.

NanoShell.gpu.setFPSCap(fps: number): boolean

Dynamically caps web engine frame rate to 30, 60, 120, or 144 FPS at runtime.
